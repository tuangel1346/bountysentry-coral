# Three-minute demo script

## 0:00–0:25 — Problem

Show the target GitHub bounty. Explain that its reward does not reveal assignment, competition,
repository health, or payment evidence. BountySentry purchases that due diligence before committing
an engineering agent.

## 0:25–1:15 — Live market

Open the BountySentry dashboard and click **Audit a bounty**. Point out the public issue URL and budget,
two competing bids, one explicit decline, and the buyer's award. Show the protocol states advancing
from `WANT` through `DEPOSITED`.

## 1:15–2:10 — Evidence delivery

Open the delivered audit panel. Highlight the risk score, recommendation, attempting users, linked
pull requests, repository signals, and evidence-backed warnings. Follow the source link to prove the
report is reproducible rather than invented by a model.

## 2:10–2:40 — Settlement

Show `DELIVERED → RELEASED`, then open the deposit and release transactions in Solana Explorer on
devnet. Explain that the payout wallet and amount were bound before work began.

## 2:40–3:00 — Close

Show the architecture: buyer and competing sellers coordinate over CoralOS; the winning seller fetches
GitHub evidence; Solana escrow settles. Close with: “Agents should not trust listings. They should buy
proof.”
